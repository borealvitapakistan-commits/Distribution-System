## Objective
Resolve Supabase's pending core.0007 migration so workbook imports can proceed. Preserve both legacy and current logo data, create a verified private database backup and apply only the pending migration.

## Tasks
1. Add/test a preservation step before dropping legacy logo columns: copy missing logo records without overwriting newer ones, and restore legacy fields on reverse migration.
2. Inspect live logo state, create/verify a complete public-schema database backup locally and in private storage, apply the migration, then verify logo hashes, record counts, schema, migration state and app health. Do not import user data.
