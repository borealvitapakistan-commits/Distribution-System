# Settings data export and replacement import

## Objective
Export all stored application records and referenced uploads in one ordered CSV. Import that format by preserving a dated private backup, then replacing current data atomically. Defer backup browsing.

## Context
Django / SQLite; owner-only Settings dropdown. Existing data/backups files are user data and must remain untouched. Sessions and API tokens are transient credentials and are never exported; replacement invalidates them.

## Tasks
1. Implement versioned, complete CSV serialization, strict validation, embedded media, private dated backup, and transactional replacement. Verify round trips, failure rollback, relationships and backup preservation.
2. Add Settings entry and owner-only export/import page, explicit replacement acknowledgement, download and import endpoints. Verify permissions and UI rendering.

## Success criteria
A single exported CSV restores all persistent models and attachments. A backup failure prevents deletion. Invalid imports cannot partially replace data. Backups persist independently of replaced database records. No changes to real data during validation.
