# Product workspace inspired by supplied Shopify screenshots

## Objective
Make product listing, creation, editing, deletion, and inventory inspection convenient using the supplied visual references.

## Context
- List scope is Product, Status, and Inventory.
- Product page uses grouped editable cards for title/description/media/category, price, inventory, shipping, and supplement details.
- Use existing fields and stock ledger. In-transit stock is tracked; there is no separate reservation ledger to invent committed values from.
- Preserve previous user decision to archive records with trading history.
- Existing import/export, package pricing, bottle pricing, ingredients, uploads, and validation must keep working.

## Tasks
1. Add tested inventory summaries and owner-only product lifecycle actions with review/confirmation and preserved history.
2. Build the list and unified editable product page, including media, description editing, stock by location, existing pricing tools, and grouped fields.
3. Verify create/edit/delete, filtering/selection, uploads, and responsive layouts in an isolated database; run relevant regression checks and record results.

## Success criteria
- List focuses on three requested columns with working search, status tabs, pagination, and selection actions.
- Clicking a product opens its editable details with real inventory by warehouse.
- Every displayed control works with existing data; no fabricated stock metrics or unsupported integration controls.
- Deletion requires review and confirmation, preserves trading history, and records audit events.
- Errors preserve submitted values; uploads and ingredients remain supported.
- Existing local records are not changed by browser verification.
