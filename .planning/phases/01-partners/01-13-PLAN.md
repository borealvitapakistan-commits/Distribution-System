# Recover attachments and unblock faithful backups

## Objective
Fix the missing-attachment export/import failure without dropping records, pretending lost bytes were backed up, or treating storage outages as missing files.

## Tasks
1. Recover exact matching local files to their absent private-storage paths. Add explicit Attachment Issues metadata for files already absent, preserving original record references in exports/backups/restores. Keep permission/network/read failures blocking and report the exact record/file.
2. Verify tests and a real Supabase backup/export without importing business data, restart the app and record remaining unavailable attachments.

## Success criteria
Missing existing files no longer block backing up all record data. Real missing references are declared and retained; tampered/incomplete file parts still fail. Storage failures abort before deletion. Available local data is recovered with verified hashes. No live workbook import or record deletion.
