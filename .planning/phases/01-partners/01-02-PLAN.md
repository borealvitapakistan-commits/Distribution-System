# Resolve linked products when deleting a manufacturer

## Objective
Replace the deletion blocker with a review page that lets the owner reassign, hold, or delete each linked product.

## Context and decisions
- User approved archiving records with order, stock, or sales history and preserving that history.
- Products can be linked directly or through supplier package prices, including multiple suppliers.
- Manufacturer history includes orders and supplier warehouses.
- Preserve existing target supplier prices on duplicate package sizes; explain this before confirmation.

## Tasks
1. Add archival fields and transactional deletion resolution with explicit per-product decisions, stale-review protection, permissions, and audit events. Test reassignment, hold, deletion, archives, pricing conflicts, and rollback.
2. Replace immediate deletion with a review page listing linked products, package prices, and retained history. Require explicit confirmation, show validation inline, make held products available to owners, and verify the complete UI flow.

## Success criteria
- GET reviews dependencies without changing data; POST requires confirmation and a valid, current review.
- Each linked product has an explicit reassign/hold/delete decision.
- Existing history survives archiving, while unused records can be physically removed.
- Active catalog/manufacturer lists and new-order choices exclude archived records.
- No existing data is deleted by verification against the user's local database.
- Relevant tests and desktop/mobile browser checks pass.
