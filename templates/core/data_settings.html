Import Data

Choose an Excel workbook (.xlsx) exported by this app (up to 100 MB). Edit values or add new rows in the category sheets; leave Record ID blank for new records. Import replaces all current data, including user accounts.

Keep sheet names and column headers. Use linked ID columns or a unique linked Name for new links. The Read Me sheet explains dates, defaults and attachments.

Before replacing anything, the app saves a separate backup of your current records and attachments with today's date and time. Existing backups stay saved. Backup browsing will be added later.

After import, sign in with an owner account from the imported workbook. If import fails, your current data stays unchanged.
